# Contributing to Awesome AI Agents

Thanks for your interest in contributing!

## Guidelines

- **One tool per line** — Use the format: `- [Name](URL) — One-line description.`
- **No duplicates** — Search the list before adding.
- **Real tools only** — Must be publicly available (open-source or commercial with a public page).
- **Descriptions matter** — Write honest, useful descriptions. No marketing fluff.
- **Alphabetical within sections** — Keep entries sorted within their category.

## How to Add an Entry

1. Fork this repository
2. Add your entry to the appropriate section in `README.md`
3. Submit a pull request with a brief explanation of why it belongs

## What We Won't Accept

- Self-promotional entries without genuine utility
- Tools that are abandoned or unmaintained (no commits in 12+ months)
- Duplicate entries or entries that don't fit any category
- Entries without working links

## Quality Bar

Every entry should pass: "Would an AI engineer building agents find this genuinely useful?"

If yes, submit it. If you're unsure, open an issue first.
